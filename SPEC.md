# Leaf: lightweight Markdown reader for macOS

## Goal
A fast, native Mac app that opens `.md` files by double-click and shows them formatted. Cmd+E toggles to raw editing. Notes tagged `#math` get Antinote-style inline arithmetic and currency conversion. Personal use only. Not for the App Store.

## Stack (do not substitute)
- Swift + SwiftUI + AppKit, macOS 14+. Edited in VS Code. **No Xcode project.**
- Toolchain: Apple Command Line Tools only (`xcode-select --install`). Built with Swift Package Manager (`Package.swift`, one executable target). VS Code extension: Swift (swiftlang).
- `build.sh` (bash):
  1. `swift build -c release`
  2. Assemble `Leaf.app/Contents/{MacOS,Resources}`; copy in the binary, `Info.plist` and the `web/` folder.
  3. Ad-hoc sign: `codesign --force --deep --sign - Leaf.app`
  4. Copy to `~/Applications/`, then re-register with Launch Services so Finder sees the file types.
- `Info.plist` is a plain file in the repo, not generated by a tool.
- No App Sandbox.
- Document handling: an `NSDocument` subclass with SwiftUI views hosted inside. Gives open/save, the unsaved-changes dot, Open Recent, native window tabs, detection of outside changes.
- Rendering: `WKWebView` with bundled JS in `Resources/web/`. Everything local, no CDN, works offline:
  - markdown-it (tables, task lists, strikethrough)
  - highlight.js
  - math.js (arithmetic, units, currency)
- Edit mode (v1): a plain `NSTextView`, monospaced, no rich text.

## Features

### 1. Open and default app
- Declare document types in `Info.plist` for `.md` and `.markdown` (UTI `net.daringfireball.markdown`), role Editor, so it can be default via Get Info → Open with → Change All.
- Also open from File → Open, Open Recent, drag onto Dock icon, and `open -a Leaf file.md`.
- Each file opens in its own window. Native window tabs enabled.

### 2. Reading view (default)
- GitHub-style typography: max width about 760px, comfortable line height, system font, monospaced code.
- Follows system light/dark automatically.
- markdown-it with `html: false`. Raw HTML in files must not render (files are AI-written). No JavaScript from file content runs.
- Relative image paths resolve against the file's folder. Use `loadFileURL` with read access to that folder.
- Clicking a link opens the default browser, never inside the app.
- Cmd+Plus / Cmd+Minus change zoom. Zoom remembered across launches.
- Scroll position kept across reloads and across switching views.

#### Text wrapping
- Body text wraps to `min(reading width, window width)`. The page itself never scrolls sideways.
- Code blocks: no wrapping; each block scrolls sideways on its own. Setting "Wrap code blocks" defaults to off.
- Tables: wrapped in a box that scrolls sideways, so wide tables never widen the page.
- Long words, URLs, paths: `overflow-wrap: anywhere`.
- Line breaks: standard Markdown (markdown-it `breaks: false`). Setting "Treat line breaks as breaks" defaults to off.
- Edit mode: soft-wrap to window width. Never insert line breaks into the file.
- Math answer pills use `white-space: nowrap` and stay attached to the end of their line.

### 3. Edit mode
- Cmd+E toggles Reading / Edit. Cmd+S saves.
- Switching back to Reading re-renders from the current text, even if unsaved.

### 4. Auto-reload
- File changes on disk and no unsaved edits: reload silently, keep scroll position.
- Unsaved edits: show a small bar "File changed on disk: Reload / Keep mine".

### 5. `#math` mode

**Where calculations happen**
- A line containing only `#math` turns on math for everything below, until a line containing only `#endmath` or end of file.
- A fenced code block with language `math` also counts as a math block.
- Nowhere else is calculated. Ordinary docs render exactly as normal Markdown.
- In Reading view the `#math` and `#endmath` lines are hidden.

**Line rules (inside a math region)**
- A line ending in `=` gets its answer shown right after the `=`, in a subtle pill. The answer is never written into the file in v1.
- Labels: `Lunch: 12 + 8 =` shows `20`. Text before the last colon is a label and also becomes a variable (lowercase, spaces → `_`), here `lunch`.
- Variables: `rent: 1800` (no `=`) defines `rent` silently. Later lines can use it, e.g. `rent * 12 =`.
- `ans` = previous answer. `total` = sum of all answers since the last blank line.
- Supported: `+ - * / ^ %`, brackets, `20% of 450`, number formats like `1,200` and `1.5k`, units such as `5 km in miles` or `3 hours in minutes` (math.js).
- If a line can't be worked out, show nothing. Never show error text in the document.

**Currency**
- Syntax: `100 usd in sgd =` or `100 usd to sgd =`. Codes are 3-letter ISO, case-insensitive.
- `$` always means SGD (`$50`, `50$`). No other currency symbols recognised. Every other currency uses its code, e.g. `20 eur`, `5000 jpy`.
- A number with no currency stays a plain number.
- Mixed sums work, e.g. `$50 + 20 eur in usd =`. If no target is given, mixed-currency answers show in SGD.
- Rates: Frankfurter (ECB daily rates, free, no key). **Check the current endpoint in Frankfurter's own docs before coding.**
- Register each currency as a math.js unit: EUR as base, others defined from the rates.
- Cache rates as JSON with their date in `~/Library/Application Support/Leaf/`. Refresh in the background when the cache is older than 24 hours, so opening a file never waits on the network. Offline: use the cache. No cache at all: currency lines show nothing.
- Below each math region, a small grey note: "Rates: ECB, <date>".

**Number formatting**
- Thousands separators. Currency to 2 decimal places. Other numbers up to 6 significant digits, trailing zeros removed.

### 6. Settings (minimal)
- Font size, reading width (narrow / medium / wide), "Wrap code blocks" (default off), "Treat line breaks as breaks" (default off).
- No "Default currency" setting; SGD is fixed.

## Out of scope for v1
Vault or folder sidebar, search across files, sync, plugins, LaTeX, export, live results while typing in edit mode.

## Build phases (each must work before starting the next)
1. Package.swift + build.sh + Info.plist; open a `.md` → formatted view, dark mode, links, images, wrapping rules, default-app setup.
2. Edit toggle, saving, auto-reload with conflict bar.
3. `#math` arithmetic, labels, variables, `ans`, `total`.
4. Currency: fetching, caching, conversion, rates note.
5. Settings.

## Acceptance tests
- Double-clicking a `.md` in Finder opens it formatted in under 0.5 s.
- `echo "new line" >> file.md` while open → view updates, scroll position stays.
- A file containing `<script>alert(1)</script>` shows nothing harmful.
- A doc without `#math` containing "Cost: 5 + 5 =" renders as plain text, no answer.
- Inside `#math`: `rent: 1800` then `rent * 12 =` shows `21,600`.
- `100 usd in sgd =` shows a number with 2 decimals, still works with Wi-Fi off after the first fetch.
- A 300-character line of text in Reading view wraps; no sideways page scroll.
- A 200-character code line scrolls inside its block only.
- A 12-column table scrolls inside its box only.
- `$100 in usd =` and `100 sgd in usd =` give the same answer.
